# Tasklane: a sample app for Babelize

A small Next.js App Router landing page with its text hardcoded in English, the way most apps start.

It's the sample project in the [Babelize dashboard](https://app.babelize.co): pick **Try a sample app** when you create a project and Babelize finds the hardcoded strings, sets up next-intl, and translates them. Or run it yourself:

```bash
npx babelize translate --to fr,de,ja
```

To see the finished result, with the unedited Babelize run and the review fixes as separate commits, look at [babelize/examples](https://github.com/babelize/examples).

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
